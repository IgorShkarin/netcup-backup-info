Privacy policy

Netcup Backup · Updated 23 October 2026

Netcup Backup is a personal server backup utility maintained by Igor Shkarin. It is intended for the owner's use and is not a public backup service.

Google Drive access

The app requests the https://www.googleapis.com/auth/drive.file permission. It creates a dedicated backup folder, uploads encrypted archives and checksum files, lists its backup files and downloads them to verify integrity. It does not request access to unrelated Drive files, Gmail, contacts or calendars.

Storage and use

The owner encrypts backup payloads before upload. OAuth credentials and verification records are stored on the owner's server. The private decryption key is held separately. Copies may also be stored in the owner's private GitHub backup repository. Access tokens and client secrets are not published on this website or in the public information repository.

Sharing

Google user data is used only to operate and verify the owner's backups. It is not sold, used for advertising, shared with other users, or used to train AI models. Data is transmitted to Google Drive and, for encrypted backup copies, to the owner's private GitHub repository.

Retention and control

The owner controls backup retention and may remove backup files from Drive and GitHub. Revoking the app's access in Google Account settings prevents future authorized operations; it does not automatically delete existing backup files.

Contact

Contact the maintainer through the maintainer's GitHub profile. Do not include secrets or backup content in public messages.
